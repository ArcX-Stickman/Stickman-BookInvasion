# Stickman: Books Invasion

**A Solo-Developed 2D Action Platformer Built with Unity and C#**

*An independent game project combining fast-paced combat, hand-drawn animation, boss encounters, and an original story.*

## Overview

**Stickman: Books Invasion** is an independently developed 2D action platformer inspired by my interest in video games, anime-style fight choreography, and expressive animation. Built from the ground up in Unity using C#, the project brings together programming, game design, animation, combat systems, and storytelling into one cohesive experience.

The game follows a stickman hero confronting an invasion of books, turning an unconventional premise into a foundation for action-packed encounters, distinctive characters, and imaginative set pieces.

As a solo developer, I take responsibility for the project's development, including gameplay programming, combat design, 2D animation, story development, cutscenes, and overall creative direction.

## Key Features

- **Action-Oriented Combat:** Design and implement combat encounters focused on responsiveness, timing, and readable enemy attacks.
- **Boss Encounters:** Develop distinctive boss fights that challenge players to recognize attack patterns, react strategically, and adapt.
- **2D Animation and Fight Choreography:** Create hand-drawn animations and cinematic action sequences inspired by anime and expressive action games.
- **Original Story and Characters:** Build a fictional world with original characters, story sequences, and encounters that connect gameplay to narrative.
- **Gameplay Programming:** Use C# and Unity to develop player interactions, enemy behavior, combat mechanics, and gameplay systems.
- **Iterative Development:** Refine mechanics, visuals, and encounters through experimentation, playtesting, and rebuilding systems that do not work as intended.

## Development and Technical Work

This project has challenged me to work across several disciplines of game development.

**Programming — C# and Unity**  
Implement gameplay systems and coordinate the interactions between the player, enemies, combat mechanics, and encounters.

**Game Design**  
Develop combat mechanics, enemy attack patterns, boss phases, player feedback, and encounters that reward observation and adaptation.

**Animation and Visual Direction**  
Create 2D character animations and choreographed action sequences, balancing visual impact with gameplay readability.

**Narrative and Presentation**  
Develop the game's premise, characters, cutscenes, and environmental storytelling to give the gameplay a recognizable identity.

**Problem-Solving and Iteration**  
Use development and playtesting to identify weaknesses, rethink design decisions, and improve the experience rather than settling for the first working implementation.

## Design Philosophy

My goal is to create an action game that feels expressive and memorable, where gameplay and animation work together to communicate the impact of each encounter.

I am particularly interested in how programming and artificial intelligence can make enemy behavior less predictable and more engaging. Working on this project has helped me explore the relationship between technical implementation and the player's experience.

Rather than treating game development as programming alone, I approach it as a combination of engineering, design, animation, and storytelling.

## Current Development

The project is being developed incrementally, with the initial playable demo focused on the tutorial and first major boss encounter. Additional story content and encounters are part of the broader development plan.

As development continues, I am refining the gameplay, improving the presentation, and expanding my understanding of how to build a complete game as an independent developer.
